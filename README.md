# Hero vs Dragon (Pixel Fireborn) 🎮🔥

An interactive 2D web-based obstacle dodger game built with pure HTML, CSS, and JavaScript.

## 🕹️ Gameplay & Controls

Take control of the hero (warrior) and dodge incoming attacks from the dragon / attacker to increase your score!

- **Up Arrow (`↑`)**: Jump over obstacles
- **Right Arrow (`→`)**: Move hero forward
- **Left Arrow (`←`)**: Move hero backward

## 🛠️ Built With

- **HTML5**: Game structure and canvas container
- **CSS3**: Animations, sprites, and responsive styling
- **JavaScript (Vanilla)**: Game mechanics, collision detection, score calculation, and audio effects

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Saurav21-cloud/Hero-vs-dragon-game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Hero-vs-dragon-game
   ```
3. Open `project.html` in your web browser.
